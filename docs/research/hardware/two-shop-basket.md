# Final Two-Shop Basket

## Recommendation

Use a two-shop split:

- `Reichelt` for the M5Stack-branded core node hardware
- `TinyTronics` for the non-M5Stack sensor modules

Why this split:

- `Reichelt` is the strongest confirmed source for `AtomS3 Lite` and `ENV-III`
- `TinyTronics` has a very cheap direct `BH1750` lux module and multiple capacitive moisture sensor options
- this keeps the basket pragmatic instead of forcing everything through one weaker compromise shop

- `2x M5Stack Unit ENV-III`

## Expected Paid Total

With shipping from two shops, expect roughly:

- cheapest acceptable basket: about `65-80 EUR`
- better-known moisture probe basket: about `72-90 EUR`

The range depends on:

- actual shipping cost to Belgium from both shops
- whether you need extra cables
- whether some sensor modules already include the cables you need

## My Recommendation

If you want the most pragmatic basket:

- `Reichelt`: `2x AtomS3 Lite`, `2x ENV-III`
- `TinyTronics`: `2x BH1750`, `2x Capacitive Soil Moisture Sensor Module with Cable`

If you want the slightly safer moisture probe choice:

- keep the same `Reichelt` basket
- switch TinyTronics moisture probes to `2x DFRobot Gravity Analog Capacitive Soil Moisture Sensor`

## Final Take

I would choose:

- `Reichelt` for the M5Stack core
- `TinyTronics` for `BH1750`
- and probably the `DFRobot` moisture probes if you want a bit more confidence, otherwise the `4 EUR` capacitive probes if you want to stay lean
