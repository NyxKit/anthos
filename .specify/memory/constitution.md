# Anthos Constitution

## Core Principles

### I. Project-First Development
All features should start with clear specifications before implementation.

### II. Documentation as Source of Truth
All technical decisions must be documented in the specs/ directory.

### III. Test-Driven Development
Tests should be written before implementation when possible.
