# Quickstart: Nodes Grid

## Verify the feature
1. Open the dashboard and confirm the node summary shows a compact claimed-node grid.
2. Open the nodes page and confirm the same shared grid shows the full claimed-node list.
3. Open an unclaimed node from the nodes page, complete the claim flow, and confirm it appears in the claimed list after the view refreshes.

## Useful checks
- The dashboard should never show more than the configured compact limit.
- The nodes page should show all claimed nodes without a separate grid variant.
- Empty states should appear when no nodes exist for the current view.
