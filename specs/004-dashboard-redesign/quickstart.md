# Quickstart: Dashboard Design Integration

**Phase**: 1 - Design  
**Date**: 2026-04-07

## Running the Dashboard

### Prerequisites

- Node.js 20+
- pnpm (workspace)

### Commands

```bash
# Install dependencies
cd anthos
pnpm install

# Start development server
cd app
pnpm dev

# Build for production
cd app
pnpm build
```

## Project Structure

```
app/
├── src/
│   ├── dashboard/       # Dashboard feature
│   │   ├── views/       # DashboardView.vue
│   │   ├── components/  # NodeCard, SensorList, StatusIndicator
│   │   ├── stores/      # telemetry.ts (Pinia store)
│   │   └── api/         # readings.ts (API client)
│   ├── nodes/           # Node management
│   └── shared/          # Router, types, assets
```

## Key Files to Modify

1. `app/src/dashboard/views/DashboardView.vue` - Main layout
2. `app/src/dashboard/components/NodeCard.vue` - Node display
