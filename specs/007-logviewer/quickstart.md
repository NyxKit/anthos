# Quickstart: Log Viewer

## Goal

Verify that log history and live updates are visible in the viewer.

## Steps

1. Start the API server.
2. Start the frontend app.
3. Generate a few node messages.
4. Open the logs area in the app.
5. Confirm the newest entries appear first.
6. Switch to an earlier day and confirm historical entries load.
7. Apply a filter and confirm the results narrow correctly.

## Expected Result

- Live messages appear without reloading.
- Historical logs can be browsed by day.
- Old data stays bounded by the retention window.
